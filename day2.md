# Day 2 - Prompt Engineering

## Objective

Learn the difference between a weak prompt and an engineered prompt.

---

## Weak Prompt

Create an image explaining Prompt Engineering.

### Result

The image was generated but lacked structure, branding, and specific design requirements.

---

## Engineered Prompt

Create a square LinkedIn post (1080x1080).

Theme:
- Claude-inspired colors
- Professional and minimal design

Title:
Prompt Engineering

Include:
- Weak Prompt → Basic Output
- Engineered Prompt → Better Output

Add:
ABtalks 60 Days Claude Challenge

### Result

The output was more structured, visually appealing, professional, and suitable for LinkedIn.

---

## Key Learnings

1. Better prompts produce better outputs.
2. Context improves AI performance.
3. Specific instructions improve design quality.
4. Prompt engineering saves time and reduces revisions.

---

## Conclusion

Prompt engineering is not about using complex words.
It is about giving clear instructions, context, constraints, and goals.

Better prompts lead to better results.
